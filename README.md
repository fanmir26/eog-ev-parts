# EOG EV Parts

BYD-first aftermarket replacement parts website for overseas Chinese EV repair markets.

## Project Type

Static website prototype built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - page content and structure
- `styles.css` - responsive layout and visual design
- `script.js` - quote form and email draft behavior
- `assets/hero-ev-parts.png` - local hero image

## Deployment Recommendation

Use GitHub + Cloudflare Pages:

1. Create a GitHub repository, for example `eog-ev-parts`.
2. Push this folder to the GitHub repository.
3. In Cloudflare Pages, create a new project from that GitHub repository.
4. Use these build settings:
   - Framework preset: None
   - Build command: leave empty
   - Build output directory: `/`
5. Add a custom domain after the first deployment succeeds.

## Business Positioning

EOG EV Parts focuses on BYD replacement parts first, while also covering major Chinese EV brands including MG, Geely, Chery, GWM, XPeng, NIO, Leapmotor, Zeekr, and Aion.
